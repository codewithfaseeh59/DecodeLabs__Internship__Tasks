# Brewed Awakenings ☕
A static coffee shop website built with pure HTML, CSS, and vanilla JavaScript.

---

## 📁 Project Structure

```
project/
├── index.html      → Page structure & content
├── style.css       → All styling & media queries
├── script.js       → Hamburger menu toggle
└── README.md       → You are here
```

---

## 📄 Pages & Sections

| Section    | Description                              |
|------------|------------------------------------------|
| Navbar     | Sticky header with logo and nav links    |
| Hero       | Full-width intro with image              |
| About      | Story, description, and stats            |
| Menu       | 6 item cards with image, name, price     |
| Gallery    | Photo grid showcasing the cafe           |
| Visit Us   | Address, hours, contact info             |
| Footer     | Logo, copyright, nav links               |

---

## ✅ Key Features

- Semantic HTML5 structure (`header`, `section`, `article`, `footer`)
- External CSS — no inline styles
- CSS Grid for layout (hero, about, menu, gallery, visit)
- CSS custom properties (`--cream`, `--dark`, `--warm`, etc.)
- Smooth scroll behavior
- Hover effects on nav links, menu cards, gallery images
- FadeUp animation on hero text
- Fully responsive — tablet (1024px) and mobile (768px)
- Hamburger menu with animated X toggle for mobile

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Fonts — Playfair Display, Jost
- Unsplash — images

---

## 🚀 How to Run

1. Download or clone the project folder
2. Make sure all 3 files are in the **same folder**
3. Open `index.html` in any browser

> No installation, no dependencies, no build step needed.

---

## 📱 Responsive Breakpoints

| Breakpoint | Layout                                      |
|------------|---------------------------------------------|
| > 1024px   | Full desktop — 2 column grids               |
| ≤ 1024px   | Tablet — adjusted padding, 2-col menu       |
| ≤ 768px    | Mobile — single column, hamburger menu      |
